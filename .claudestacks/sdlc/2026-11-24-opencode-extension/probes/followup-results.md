  (`rootHasOpencode: true`).

  commits, `ctx.location.project.id` was `"global"`.

    await ctx.shell.hook("create.before", (e) => {

  then spawns with `invocation.env` (entries whose value is `undefined` are dropped)

- The hook fires once per `shell` call, in the main session and in the subagent child alike. To tell
  them apart, pair it with the `execute.before` of the `shell` tool, which carries `sessionID`/`agent`
  (fu-02 log). Both fire in that order.

  `{read,*.env.example,allow}`, `{browser,*,deny}`, `{skill,browser,deny}`. So `read *.env` stays

  only in the child's request (req 3). The parent's entry is absent from the child's request, and the
  child's entry is absent from every parent request.
- All four turns used the same session (`ses_df18951f1ffefGDWu64pCsHTyy`; `-c` picked it), and
