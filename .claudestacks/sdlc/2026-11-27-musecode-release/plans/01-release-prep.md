# Musecode Release Preparation Implementation Plan

**Goal:** The repository is ready for the maintainer's coupled 1.1.0 release.

**Architecture:** Versions, changelogs and documentation only; no code change. The three
changelog entries that already describe musecode under `Unreleased` are dated, the two crates
move to 1.1.0, every "ships with the next `packs-v*` release" claim becomes a released claim,
and the `RELEASING.md` verification learns the musecode extension. Tagging, crates.io publishing
and closing issue #16 stay outside this plan as the maintainer's irreversible steps (the intent's
constraint, following the 1.0 chain's `08-release.md` precedent).

**Tech Stack:** Cargo workspace (`Cargo.toml`, `Cargo.lock`), cargo-make (`Makefile.toml` tasks),
Markdown (changelogs, README, CLAUDE.md, mdBook under `book/`).

**Content authority:** the chain's approved `intent.md` (spec skipped), Desired outcome and
Constraints; `RELEASING.md` "Later releases" steps 1 and 4 for the order and the verification
shape.

## Risks

- **Date slip.** The changelogs are dated for the intended release day. If merging or tagging
  slips to a later day, the date must be amended before the release pull request merges; a wrong
  date is cosmetic but permanent once tagged.
- **Tag order.** Pushing `agentstacks-cli-v1.1.0` before `packs-v1.1.0` would let the new binary
  resolve musecode to `packs-v1.0.0` and fail on the missing directory — the exact failure of
  issue #16, one step later. The runbook's order (packs first) is a constraint, not a preference.
- **Irreversibility.** Crates.io publishing cannot be undone. Nothing in this plan publishes;
  the maintainer publishes only after the step-4 verification passes on the tagged tree.
- **Example counts.** `ch01-02-first-project.md` states file counts for the claude setup.
  Task 3 does not assume they carry over: its `git diff --stat packs-v1.0.0..HEAD` proof over
  the three example packs must print nothing before the tags in that chapter are rewritten, and
  the task stops if it prints anything.
