# AGENTS.md

## Commands

- `cargo make test` — run the full test suite
- `cargo make clippy` — run the lint task
- `cargo make fmt` — run the format task

## Code Map

- `crates/` — crates
- `book/` — project documentation
- `.github/` — project configuration

## Conventions

- Use `mod` declarations and `use` imports in Rust source files.
- Use `.rs` files for integration tests in a crate's `tests/` directory.
