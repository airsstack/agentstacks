# Getting Started

Two steps take a project from nothing to a working setup:

1. [Install agentstacks](ch01-01-installation.md): a prebuilt binary, or `cargo install`.
2. Set up [a first project](ch01-02-first-project.md): `init`, `plan`, `apply`, `doctor` and
   `update`, with the output each prints.

Moving from the claudestacks plugins instead? Read
[Moving from the claudestacks Plugins](ch03-00-migration.md).
