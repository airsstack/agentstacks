# Changelog

All notable changes to the `claude` tool extension are recorded here. The
format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
the extension follows [Semantic Versioning](https://semver.org/spec/v2.0.0/):
the version moves if and only if the extension's shipped content changed.
Each release is tagged `ext-claude-v<version>`.

## [1.1.0] - 2026-11-27

Baseline. Version 1.1.0 as last released under the `packs-v*` bundle tags
(`packs-v1.2.0`); from here this file records each release of `claude`.

### Changed

- Files the extension writes in Markdown and Lua carry a `generated by
  agentstacks` line (after the frontmatter of a Markdown file that has one).
  JSON files, copied pack files and other formats are not stamped.
