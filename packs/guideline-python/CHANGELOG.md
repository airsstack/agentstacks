# Changelog

All notable changes to the `guideline-python` pack are recorded here. The
format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
the pack follows [Semantic Versioning](https://semver.org/spec/v2.0.0/): the
version moves if and only if the pack's shipped content changed. Each release
is tagged `packs-guideline-python-v<version>`.
