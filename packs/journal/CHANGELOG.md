# Changelog

All notable changes to the `journal` pack are recorded here. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the pack
follows [Semantic Versioning](https://semver.org/spec/v2.0.0/): the version
moves if and only if the pack's shipped content changed. Each release is
tagged `packs-journal-v<version>`.

## [1.0.0] - 2026-11-25

Baseline. Version 1.0.0 as last released under the `packs-v*` bundle tags
(`packs-v1.0.0`); from here this file records each release of `journal`.
